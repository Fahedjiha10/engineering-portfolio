# ESP8266 MQTT / Losant IoT

Arduino firmware progressing from button/LED reporting to DHT22 temperature-and-humidity telemetry. It reconnects to Wi-Fi and Losant, publishes JSON state, handles remote LED commands, and emits serial diagnostics.

All Wi-Fi and Losant credentials are replaced with `<REDACTED_FOR_PORTFOLIO>`. Configure your own values locally and never commit them.
