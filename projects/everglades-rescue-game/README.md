# Everglades Rescue Game

C++ group coursework by Fahed Jiha, Kerweins Astre, Xzavian Patrick, and Kavencci Saint Jean. The 5×5 game uses arrays, structs, menus, randomized hazards, adjacent-movement validation, combat/wait choices, and a 12-gong countdown.

```bash
g++ -std=c++17 src/main.cpp -o everglades-rescue
```

The source previously passed C++17 syntax validation. This portfolio does not claim sole authorship.
